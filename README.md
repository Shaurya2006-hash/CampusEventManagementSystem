# Campus Event Management System

## About the Project

A web-based application designed to simplify campus event planning and management. Students can explore upcoming events, register for events, and stay updated with college activities. Administrators can create, update, and manage campus events.

## Technologies Used

- React.js
- Vite
- Node.js
- Express.js
- MongoDB

## Features

- Student registration and login
- Browse campus events
- Event registration
- Admin dashboard
- Create and manage events

## Installation

```bash
npm install
npm run dev
```
